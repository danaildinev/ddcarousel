Your modern carousel

Lightweight, dependency-free, written in TypeScript. Built for modern web, responsive layouts, optional modules, typed events and a compact core - without a UI framework or runtime dependency.

  • ~9 KB gzip ESM core
  • 0 dependencies
  • ES2022 modern browsers

This showcase is using ddcarousel right now. Every main section on this page is a slide in the carousel.

One core, a lot of ways to move.

Small by design. The ESM build keeps optional features out of the initial core. Enable a module in configuration and ddcarousel loads its chunk automatically.

Prefer a classic <script> tag? A browser-ready UMD bundle is also available, with no bundler required.

  • ~26 KB gzip ESM core
  • ~9 KB gzip ESM core
  • ~4 KB per module/optional module chunks
  • UMD ready for direct browser use

Main features

  • 1. Modular architecture

    Lightweight with optional modules that load automatically when enabled.

  • 2. Events & Lifecycle

    Hook into page changes, dragging, transitions, and module lifecycles.

  • 3. Fully customizable

    Make ddcarousel your own with CSS variables, configurable controls, and extensive behavior options.

  • 4. Flexible layouts

    Horizontal or vertical, center slides, full-width layouts or automatically adjust heights... countless possibilities.

  • 5. Seamless infinite loop

    Keep the experience flowing with continuous navigation in every direction.

  • 6. Multiple Navigations

    Navigate slides naturally using your mouse wheel or trackpad. Adjustable thresholds and delays. URL hashes for direct navigation and shareable links.

  • 7. Dynamic Runtime Control

    Control navigation, inspect live carousel state, and load or unload modules on demand. Build interactive experiences without rebuilding the carousel.

  • 8. Advanced User Experience

    Deliver smooth, intuitive interactions with customizable drag snapping, smart autoplay, keyboard controls, and lazy loading.

Use it your way

npm, ESM, UMD or CDN

Modern bundler or a plain script tag? The same carousel API is available either way.

npm / ESM

Recommended for modern applications.
npm i ddcarousel
Get the lightweight ESM core with automatic loading of optional feature modules. Only load what you need. Latest release on

Browser / UMD

No bundler required
<script src=".../ddcarousel.umd.min.js></script>
Drop a single, self-contained bundle into your page and start building. Perfect for simple websites and quick integrations. Open jsDelivr
